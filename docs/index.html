Get started

Install on your Mac

  1. Download and unzip DiskManager-macOS.zip.
  2. Move DiskManager.app to Applications and open it.
  3. Choose a drive or drop a folder into the app to start a scan.

The download uses an ad-hoc signature and is distributed without Apple notarization. If macOS blocks the first launch, check that the zip came from this project and see Apple’s instructions.
