    Install

    1. On a Mac, download and unzip DiskManager-macOS.zip, then move DiskManager.app to Applications.
    2. On Windows, download DiskManager-Windows-x64.exe. It is a single file with nothing to install.
    3. Open DiskManager and choose a drive, or drop a folder onto the window, to start a scan.

    The Mac app is ad-hoc signed and not notarized by Apple. If macOS blocks the first launch, check that the zip came from this project, then follow Apple’s instructions.

    The Windows app is not code-signed, so Windows may show “Windows protected your PC” the first time. Choose More info, then Run anyway.

    Questions

    Does it upload my files?

    No. File names, paths and sizes are processed on your computer. The app has no analytics and uploads no scan results.

    What happens when I delete something?

    Items sent to the Trash (or Recycle Bin on Windows) free up space once you empty it. Permanent deletion cannot be undone, so the app asks you to choose it explicitly.

    Why does macOS block it the first time?

    The download is ad-hoc signed and not notarized. Check the checksum and that the zip came from this project’s releases before you allow the app to open.

    Does it need administrator access?

    Only for an administrator scan or when removing a snapshot. The app asks first.

    Which computers does it run on?

    macOS 14 Sonoma or later, on Apple silicon and Intel Macs, and 64-bit Windows 10 or 11.
