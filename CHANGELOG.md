# Changelog

## 1.1.0

- Add a native Windows version for 64-bit Windows 10 and 11, downloaded as a single `.exe`.
- The macOS app is unchanged apart from the version number.

## 1.0.0

- Scan mounted drives and folders on macOS.
- Explore disk usage in a sunburst chart and preview files with Quick Look.
- Collect items for review before moving them to the Trash or deleting them.
- Inspect local APFS snapshots and run optional administrator scans.
- Distribute one macOS download for Apple silicon and Intel.
